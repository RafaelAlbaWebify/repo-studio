# Contributing

Contributions are welcome through the future public repository at `RafaelAlbaWebify/repo-studio` once published. Before that point the destination is reserved, not a claim of availability.

Please preserve read-only inspection, commit-pinned provenance, human control, no implicit upload, bounded requests and conservative findings. Add unit tests and, for interface changes, isolated browser regression checks. Do not include private repositories, evidence packs, API keys or user-specific paths in issues, PRs, screenshots or fixtures.
