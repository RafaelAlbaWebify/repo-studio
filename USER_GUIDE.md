# Repo Studio user guide

The in-app **Help & user guide** includes an index, workflows, synthetic-data screenshots, terminology and privacy guidance.

**Run code analysis:** Python AST scan for import cycles, complexity and conservative possibly-unused candidates.

**Scan duplications:** optional jscpd scan of committed snapshot. Separate analysis with separate status.

Human chooses evidence, reviews snippets, and authorizes sharing with external AI. Token budget is an estimate, not a validated saving.
