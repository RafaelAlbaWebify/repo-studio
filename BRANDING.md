# Repo Studio visual identity — candidate 0.9.2

- Primary mark: flat, geometrical RS monogram on a dark neutral square, no glow or gradient.
- Vector: `static/repo-studio-icon.svg`; wordmark: `static/repo-studio-logo.svg`.
- Favicon: `static/favicon.svg`; Linux desktop icon: `static/repo-studio-icon.png` (256×256).
- The brand uses only the app's own open-source files; final visual acceptance is the developer's decision.
- Existing Omarchy menu entries are **not** rewritten by the application update. Use the optional separate icon-only installer after confirming the branding.
